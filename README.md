# 📅 Конвертер расписания РЭУ (REA Schedule Parser)

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)
[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Веб-приложение, которое автоматически скачивает расписание с сайта [rasp.rea.ru](https://rasp.rea.ru) и конвертирует его в формат `.ics`.
Это позволяет добавить расписание в **Google Календарь**, **iCloud (iPhone/Mac)** и **Outlook** за пару кликов.

## ✨ Возможности

* **Автоматический парсинг:** Сканирует расписание на весь семестр вперед.
* **Умная сортировка:** Разделяет пары на три календаря:
    * 🔴 **Экзамены и Зачеты** (чтобы точно не пропустить).
    * 🔵 **Лекции**.
    * 🟢 **Семинары и Практики**.
* **Часовые пояса:** Все события создаются с учетом московского времени (Europe/Moscow).
* **Кроссплатформенность:** Работает на iOS, Android, Windows и Mac.

## 📖 Инструкция для пользователей

1.  Перейдите по [ссылке на приложение](СЮДА_ВСТАВЬ_СВОЮ_ССЫЛКУ_НА_STREAMLIT).
2.  Введите номер своей группы **точно так же, как на сайте РЭУ** (например: `15.27д-э01/24б`).
3.  Нажмите кнопку **🚀 Получить расписание**.
4.  Дождитесь окончания загрузки (зеленая полоска дойдет до конца).
5.  Скачайте нужные файлы:
    * `reu_exams.ics` — Экзамены.
    * `reu_seminars.ics` — Семинары.
    * `reu_lectures.ics` — Лекции.

### Как добавить в календарь:

* **🍏 iOS (iPhone/iPad):** Скачайте файл, нажмите на него -> "Добавить все" (Add all).
* **🤖 Android (Google Calendar):** Откройте файл. Если не сработало автоматически: зайдите в настройки Google Календаря -> Импорт -> Выберите файл.
* **🖥 Windows (Outlook):** Просто откройте скачанный файл двойным кликом.
