# reu-schedule-parser
📅 Генератор расписания РЭУ для календаря
Эта программа автоматически скачивает наше расписание с сайта РЭУ и создает файлы, которые можно добавить в календарь на телефоне или компьютере (Google, iPhone, Outlook).

🚀 Как пользоваться
Шаг 1. Подготовка

Скачайте файл REU_Schedule.exe.

Важно: Положите его в отдельную пустую папку (программа создаст рядом несколько файлов, лучше, чтобы они не потерялись на Рабочем столе).

Шаг 2. Запуск

Запустите REU_Schedule.exe.

Откроется черное окошко (консоль). Не пугайтесь, так и должно быть!

Программа попросит ввести номер группы.

Введите его точно так же, как он написан на сайте расписания (маленькими буквами).

Пример: 15.27д-э01/24б

Нажмите Enter.

Шаг 3. Ожидание Программа начнет "бегать" по неделям и собирать пары. Вы увидите бегущие строки с номерами недель.

⏳ Это займет около 30-60 секунд.

Не закрывайте окно, пока не появится надпись "Нажми Enter, чтобы выйти...".

Шаг 4. Результат В папке с программой появятся 3 файла-календаря:

🔵 reu_lectures.ics — только Лекции.

🔴 reu_exams.ics — Экзамены и Зачеты (важно!).

🟢 reu_seminars.ics — Семинары и Практики.

Вы можете использовать все три, или выбрать только те, что вам нужны.

📲 Как добавить в календарь
🍏 Для iPhone / iPad (Apple Calendar)
Отправьте полученные файлы .ics себе на телефон (через Telegram, AirDrop или почту).

Нажмите на файл в чате/почте.

Нажмите кнопку "Добавить все" (или "Add to Calendar").

Готово! Расписание теперь в вашем родном календаре.

🤖 Для Android (Google Календарь)
Способ через телефон:

Откройте файл .ics на телефоне.

Телефон предложит открыть его через приложение "Календарь".

Нажмите "Добавить".

Способ через компьютер (надежнее):

Зайдите на сайт calendar.google.com с компьютера.

Нажмите на шестеренку ⚙️ (справа сверху) -> Настройки.

В меню слева выберите "Импорт и экспорт".

Выберите файл reu_seminars.ics (и другие по очереди) и нажмите "Импорт".

📧 Для Outlook (Windows)
Просто дважды кликните по файлу .ics на компьютере.

Outlook откроет событие и предложит добавить его в календарь.

Программа безопасна, она просто заходит на сайт РЭУ.

Программа закрывается сразу после запуска Скорее всего, вы нажали на нее внутри архива (ZIP).

Сначала распакуйте программу в обычную папку, а потом запускайте.
